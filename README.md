# Bethany Does Things

Official website and interactive puzzle playground for Bethany Does Things.

## Project structure

- `assets/` — shared brand assets, icons, audio, fonts, and organized images.
- `assets/images/` — shared imagery plus dedicated folders for Bethany, the dogs, and each puzzle category.
- `css/` — global foundations, reusable components, page styles, and game-specific styles.
- `js/` — shared site logic, reusable components, page logic, and game modules.
- `games/` — standalone game entry points, beginning with Train Track.
- `docs/` — project documentation, design decisions, and technical notes.

## Development principles

- Mobile-first, accessible, and performance-conscious.
- HTML, CSS, vanilla JavaScript, and SVG wherever practical.
- Progressive enhancement: essential content first; optional effects later.
- Keep puzzle implementations modular and reusable.
- Use lowercase, hyphen-separated folder and file names.
- Use WebP or AVIF for optimized photographic imagery where supported; retain original source files separately when useful.
